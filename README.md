CivicResolve — AI-Powered Citizen-to-Government Civic Grievance Platform🌐 Live Demo: https://261118-asvitha.github.io/CIVICRESOLVE/GitHub Repository Description:
AI-powered civic grievance platform using Google Gemini triage, live Google Maps pointers, voice reporting, SLA tracking, and photo resolution proof.OverviewCivicResolve is a transparent, single-file web application connecting citizens directly with municipal authorities to report, classify, track, and resolve civic infrastructure issues. Powered by Google Gemini AI (gemini-3-flash-preview), every submitted grievance is automatically categorized, prioritized by public safety urgency, and routed to the appropriate municipal department—complete with live Google Maps street pointers, SLA aging counters, and verified Before/After resolution documentation.Key Features1. Citizen Issue Reporting & Voice AssistantMulti-Modal Submission: Citizens report issues with a title, detailed description, street/GPS location, category, and optional geo-tagged site photo.AI Voice Complaint Assistant: Supports speech-to-form reporting and built-in voice demos across English (EN), Tamil (தமிழ்), and Hindi (हिंदी).Official Printable Receipts: Generates stamped municipal acknowledgement receipts (Print / Save PDF or copyable text) and allows withdrawing open (Reported) tickets.2. Google Gemini AI Classification, Priority & RoutingAutomated Category Detection: Classifies complaints into Roads & Potholes, Water & Drainage, Garbage & Sanitation, Streetlights & Electricity, or Public Safety & Traffic.Public Impact Priority Detection: Evaluates urgency (Critical, High, Medium, Low) with human-readable AI reasoning.Department Recommendation: Routes each complaint directly to the responsible municipal wing (Roads & Highways Dept, Water Supply & Drainage Board, Solid Waste Management, TANGEDCO / Street Lighting, Traffic & Public Safety).Zero-Config Resilience: Uses structured JSON responses from gemini-3-flash-preview with an automatic deterministic fallback classifier so the app runs reliably on public GitHub Pages without requiring an exposed API key.3. Live Google Maps & Street PointersInteractive Map / Satellite view with color-coded pins (Reported, In Progress, Resolved).Clicking any map pointer or street directory card zooms directly (z=17) to that exact location and opens the live pin inspector.4. Issue Tracking Dashboard & Public FeedTracks complaints across Reported → In Progress → Resolved workflow stages with visual progress bars and Days Existing badges.Public Feed & Ward Guardians Leaderboard: Allows neighbors to validate local issues (+5 Impact Points) and inspect transparent audit timelines.5. Municipal Admin Dashboard (Individual Officer Login + Evidence Archive)Separate Role-Based Logins with 2-Step OTP:Citizen Login: Mobile/Email + 6-digit OTP (482910)Admin Officer Login: Individual official details (Full Name, Designation/Rank, Employee ID, Department, Zone) + 6-digit Gov OTP (739154)Two-Column Resolution Workbench:Left Column (Active Queue): Priority-sorted Reported and In Progress tickets with an SLA breach watchdog banner and +48h SLA Test simulator.Right Column (Resolved Evidence & Documentation): Automatically archives resolved tickets with Before (Submitted) and After (Completion Proof) photos, signing officer credentials, one-click audit record export, and printable Daily Ward Audit Reports.Tech StackFrontend: Semantic HTML5, Tailwind CSS (CDN), Font Awesome 6, Google Fonts (Inter & Plus Jakarta Sans)AI Engine: Google Gemini API (gemini-3-flash-preview with structured JSON schema) + built-in fallback triageGeospatial: Interactive Google Maps Embed (Map & Satellite modes) with dynamic street zoomSpeech & Accessibility: Web Speech API (SpeechRecognition & speechSynthesis) + Multi-language UI (EN / TA / HI)Demo Credentials (Built-In)Portal RoleLogin DetailsDemo OTP CodeCitizen PortalAny Name & Mobile/Email (or click Citizen Login)482910Admin DashboardClick Admin Login → Demo Admin (or enter custom Officer Name, Rank & Gov ID)739154Project StructureCIVICRESOLVE/
